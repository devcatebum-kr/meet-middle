# 경쟁사 스캔 — 한국 "중간지점 찾기" 카테고리

> 조사일: 2026-09-09 · 방법: 웹 검색 + 각 서비스 직접 접속(랜딩·FAQ·스토어 페이지). 지표는 각 사이트/스토어가 스스로 표시한 값이다.

## 한 줄 결론

**링크를 공유하면 각자 자기 출발지를 넣는 "협업 방"을 가진 곳이 한 곳도 없다.** 전부 한 명이 친구들 출발지를 대신 다 입력하는 모델이다. 우리 ⑦번 기능이 유일한 구조적 차별점이고, 그게 곧 유통 루프(초대=참여)이기도 하다.

두 번째 결론: **카테고리 자체가 작다.** 법인이 운영하는 밋미들조차 자기 사이트에 "오늘 방문 106 / 총 만남 168"을 띄워둔다. 최대 규모가 1만+ 다운로드(더치, 그것도 2인 전용)다. 아직 아무도 못 먹은 시장이라는 뜻이면서, 수요 자체가 얇을 수 있다는 경고이기도 하다.

## 비어 있는 자리

1. **협업 방 = 없음.** 7곳 중 어디도 "링크를 열면 내 출발지만 넣는" 모델이 아니다. 위밋플레이스의 친구 초대는 앱 설치 + 연락처 동기화가 전제였고, 그 강요가 스토어 리뷰에서 반복적으로 까였다. 우리는 무설치·무로그인 링크 하나다.
2. **minimax를 말하는 곳 = 없음.** 쌤밋이 "이동 시간이 비슷해지도록"(분산 최소화)으로 가장 가깝고, 나머지는 "정확한 중간" 수준이다. "가장 오래 걸리는 사람의 시간을 최소화"는 아무도 언어화하지 않았다 — 우리 결과 화면엔 이미 `최대 N분` 배지가 있는데 마케팅 문구로는 안 쓰고 있다.
3. **무로그인이 선택 이유로 반복 등장.** 더치 리뷰에 "로그인 안 해도 되고", "친구들 회원가입 안 해도 돼서 타 앱보다 편하다"가 유용 평가 상위에 있다. 지금 정책(무로그인·무설치)을 유지할 근거.

## 사용자가 실제로 요구한 것 (더치 리뷰에서)

- **가중치**: "50:50 말고 70:30으로도 계산되면 좋겠다" (유용 21표). 우리 minimax를 가중 minimax로 확장하면 바로 대응된다.
- **환승 조건**: "버스 환승 0회, 지하철 1회까지" 같은 제약 선택.
- **원거리 실패**: 지방↔서울처럼 멀면 결과가 깨진다는 불만 — 우리도 후보 역 반경 6km 확장 로직이 같은 지점에서 약할 수 있다.

## 위협

- **쌤밋**이 알고리즘적으로 가장 가깝다. 방 기능만 붙이면 차별점이 사라진다. 우리 해자는 기능이 아니라 **초대 루프가 만드는 유입**이어야 한다.
- **ODsay 30콜/일 하드캡**이 성장의 즉각적 병목이다. 밋미들은 네이버+Tmap을 쓴다. 트래픽이 붙는 순간 유료 플랜 또는 대체 API 결정이 필요하다.
- **플랫폼 진입**: 카카오맵이 이 기능을 넣으면 카테고리가 사라진다. 다만 지금까지 안 넣었다.

## 그래서 무엇을 할까

1. **히어로를 솔로가 아니라 방으로.** 지금 첫 화면은 "출발지만 넣으면" — 남들과 똑같은 약속이다. 우리만 가진 문장은 "링크 하나 보내면 각자 자기 위치만 넣어요"다. 홈 CTA에만 있고 히어로엔 없다.
2. **minimax를 앞세우기.** "가장 오래 걸리는 사람 기준" — 결과 화면의 `최대 N분` 배지를 카피로 끌어올린다.
3. **가중치는 나중에.** 수요 신호는 있지만(70:30) 지금은 초대 루프가 먼저다.
4. **계측 먼저.** 방 생성 → `/s` 열람 → 참여자 추가 퍼널이 없으면 카피 A/B도 유통 판단도 못 한다. (HANDOFF §8)
